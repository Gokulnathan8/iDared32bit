#
# Options in this file take precedence over iDared 32bit's built-in defaults.
#
# ---
#
# Each line in this file sets options for one game; there should only be one
# line per game. A line should consist of the game's identifier, followed by
# a colon (:), followed by the options to apply. To find a game's identifier,
# run it and look for “App bundle info” in the log. To get a list of possible
# options, see OPTIONS_HELP.txt.
#
# Text on a line following a hash sign (#) is treated as a comment and ignored.
# Empty lines are also ignored.
